# Dev Browser
Navegador Android de pruebas para PWA, enfocado en depuración móvil.

## V1
- Navegación por URL
- Historial de sitios recientes
- Captura de console.log/warn/error/info/debug
- Copiar consola
- Permisos de geolocalización
- Diagnóstico básico de GPS
- Limpieza de caché, cookies y almacenamiento WebView
- Recarga y navegación atrás/adelante

## Abrir
Importa el proyecto en Android Studio y ejecuta la configuración `app` en un dispositivo Android.
